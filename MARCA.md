# Uso das marcas

O código deste repositório é MIT (ver `LICENSE`). As **marcas** não são.

`commente.me`, `integram.me`, `inmmerce`, `hablecon.app`, `inmplementa.me`,
`reportam.me`, `ebanner.me`, `llmbattle.dev` e `smlk.me` — os nomes, os logotipos, os
isologos e os ladrillos — são marcas de Jose Luiz. Estão aqui para que quem trabalha com
elas as aplique **certo**, não para uso livre.

## Pode, sem pedir

- Usar os logotipos para **se referir** a um produto da família: escrever sobre ele,
  linkar para ele, listá-lo entre integrações, clientes ou parceiros.
- Construir uma interface, um site, um e-mail ou um material **de** um produto da
  família, seguindo o que esta skill descreve.
- Copiar os tokens, o CSS, o SCSS, o preset e o gerador para o que você quiser —
  inclusive para um projeto que não tem nada a ver com a família. Isso é MIT.
- Estudar o sistema e citá-lo como referência de design.

## Não pode, sem autorização por escrito

- Usar qualquer logotipo da família como **sua** marca, ou dentro dela.
- Sugerir patrocínio, parceria ou endosso que não exista.
- Alterar os logotipos: recolorir, redesenhar, trocar a tipografia, distorcer, aplicar
  efeito, ou compor com outra marca. As seis regras de `usos-incorretos.md` valem para
  todo mundo.
- Registrar nome, domínio, conta ou aplicativo que se confunda com um produto da família.
- Vender os arquivos de marca, ou distribuí-los como se fossem de uso livre.

## Na dúvida

Abra uma issue em <https://github.com/zeluizr/commente-design-system/issues> e pergunte.
Resposta clara vale mais do que um pedido de retirada depois.

Sem autorização escrita em contrário, nada aqui transfere titularidade nem concede
sublicença sobre as marcas.
